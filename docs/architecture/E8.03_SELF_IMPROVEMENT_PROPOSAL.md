# E8.03 — Auditable Self-Improvement Proposal

## Implementation
The proposal artifact binds Evolution Memory, Learning Cycle, Learning Input, Opportunity and Contract Candidate into one deterministic, reviewable object.

## Required evidence
A proposal requires complete upstream provenance, evidence references and acceptance conditions. Commercial proposals additionally require financial evidence and a `partner:` scope.

## Safety invariant
Proposal formation never grants execution authority and does not mutate Core state.
