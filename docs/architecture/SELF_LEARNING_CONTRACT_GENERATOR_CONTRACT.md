# E7.61 — Self-Learning Candidate Contract Generator

## Objective

Turn verified learning context into a machine-readable partner/development contract candidate.

## Required fields

Every candidate carries generator/context identity, source references and revisions, generated revision, scope, status and validation requirements.

## Privacy

Generation is scope-bound. A candidate cannot cross into an unauthorized scope. The source itself is not copied into the candidate; provenance references are retained.

## Authority

Generated contracts begin as PROPOSED and have no authority to accept themselves, grant capability, change Core invariants, or mark implementation verified.

## Status

IMPLEMENTED / UNVERIFIED.
