# Architecture Decision and Licensing Contract

## ADR
Material architectural changes MUST record:
- decision;
- alternatives considered;
- evidence;
- consequences;
- affected invariants;
- status and supersession.

ADR records document why a change was accepted; they are not proof that the implementation works.

## Licensing
The repository MUST contain an explicit, deliberate licensing state before product distribution claims are made.
The chosen license MUST be compatible with the project's intended research, commercial-use and contribution policy.

No specific license (including GPLv3) is mandated by this contract. A later explicit decision may select permissive, copyleft, source-available or another legally reviewed model.

## Acceptance
A licensing decision and ADR convention are documented, discoverable and covered by repository checks where practical.
