# E8.13 — Open / Commercial Collaboration Proposal Boundary

## Objective
Allow the self-learning system to generate collaboration proposals while keeping open non-commercial and commercial paths structurally separate.

## Types
`OPEN_NONCOMMERCIAL` and `COMMERCIAL_PARTNERSHIP`.

## Invariants
Open non-commercial proposals carry no financial references. Commercial proposals require explicit financial evidence. Both require evidence and a rights profile. Neither creates a contract or execution authority.

PARTIAL / UNVERIFIED.
