# E7.74 — Self-Learning Collaboration Proposal Generator

## Objective
Allow the Core's Self-Learning layer to generate machine-readable proposals for commercial or open collaboration from verified evidence and existing contracts.

## Channels
- COMMERCIAL — bounded partner project / specialized Core request.
- OPEN — non-commercial research, public development or community collaboration.

## GitHub boundary
The Core may generate a publication-ready proposal artifact, but GitHub publication requires an external authorized adapter/review gate. Generation never grants authority to publish, invite users, expose private data or modify Core.

## Required content
Evidence references, requested partner inputs, deliverable contract references, scope and publication target are mandatory.

## Privacy
Private data references block publication safety.
