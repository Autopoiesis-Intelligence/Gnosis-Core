# E7.56 — Protected Core Integration Bridge

## Objective

Create a narrowly scoped proposal at the boundary between governed Self-Learning integration and Ψ-Core mutation.

## Rules

Only a PROPOSED integration record targeting common-self-learning may cross the bridge.
The bridge creates a proposal and requires explicit approval.

## Boundary

The bridge MUST NOT directly execute mutation, bypass governance, grant permissions, or import partner-private data.

IMPLEMENTED / UNVERIFIED.
