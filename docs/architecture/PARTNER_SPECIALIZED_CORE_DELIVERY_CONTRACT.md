# E7.63 — Partner Specialized Core Delivery Package

## Objective

Define a bounded delivery manifest for a specialized partner Core without exposing the private production Core.

## Package boundary

The manifest binds:
- specialized Core identity;
- contract references;
- knowledge scope;
- evidence references;
- explicit excluded private components;
- delivery revision.

The package is PROPOSED until the applicable delivery authority accepts it.

## Privacy

Partner delivery MUST preserve the declared knowledge scope. Private Core source, unrelated partner data and other excluded components are not delivery contents.
