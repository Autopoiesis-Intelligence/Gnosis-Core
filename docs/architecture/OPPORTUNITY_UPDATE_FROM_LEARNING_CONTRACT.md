# E8.10 — Learning Commit → Opportunity Update

## Objective
Feed only durable, verified learning outcomes back into the opportunity-value grid.

## Invariants
Opportunity updates require evidence and a learning commit reference. Updates can apply only after the learning commit is verified/admitted. Promotion to COMMERCIAL is not inferred from learning alone; it requires a dedicated commercial evidence gate. Updating an opportunity never creates a contract.
