# E7.54 — Knowledge Promotion Gate

## Objective

Separate accumulated specialized knowledge from knowledge proposed for integration into common Self-Learning.

## Required evidence

A promotion proposal requires:
- a recorded KnowledgeVersion;
- one or more evidence references;
- an explicit reason;
- an explicit target.

## Governance

Promotion remains a governed decision. ACCEPTED is a proposal decision record, not direct Core mutation.

## Boundary

The gate does not copy partner data, mutate Ψ-Core, grant permissions, or execute integration. Private/non-shareable material remains outside common learning.
