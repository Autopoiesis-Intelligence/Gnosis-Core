# Core Diagnostic Evidence Lifecycle

## Purpose

The Core diagnostic corpus is a permanent internal capability. It must survive removal of the external Research Machine while remaining subordinate to canonical Core authority.

## Lifecycle

```
EPHEMERAL
  ↓
OBSERVED
  ↓
REPRODUCED
  ↓
VERIFIED
  ↓
DURABLE EVIDENCE
  ↓
REUSABLE DIAGNOSTIC CASE
```

### EPHEMERAL
Sandbox output produced during one diagnostic run. It has no durable authority.

### OBSERVED
The observation is recorded with case ID, Core state/candidate identifiers, sandbox budget and provenance.

### REPRODUCED
The same diagnostic condition is reproduced under an independent or replayable execution path.

### VERIFIED
Required invariants, provenance and limitations are checked. Verification does not imply causality.

### DURABLE EVIDENCE
Verified evidence is persisted as Core evidence/history. It can be consumed by reflection and cumulative analysis.

### REUSABLE DIAGNOSTIC CASE
A repeated, stable and sufficiently characterized failure/tension may become a new immutable diagnostic case in the Core corpus. Admission requires explicit provenance and verification; evidence alone cannot silently create executable capability.

## Authority rules

1. Diagnostic evidence never mutates canonical Ψ directly.
2. A diagnostic case cannot authorize its own promotion.
3. Research Machine evidence follows the same admission path when imported.
4. Durable evidence is not automatically a new rule.
5. Repeated evidence may support Gap detection, but repetition is not proof of causality.
6. Core memory stores evidence/provenance; executable diagnostic cases are separately identified.
7. Removal of Research Machine must not remove the Core diagnostic corpus or its durable evidence.

## Research Machine relationship

External research can propose:
- diagnostic case candidates;
- counterexamples;
- hypotheses;
- evidence references.

Core must reproduce/verify them before admission to its durable corpus.

The Research Machine therefore accelerates discovery but is not required for continued diagnostic operation.
