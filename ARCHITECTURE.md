# Gnozis Genesis Architecture — Clean-Room Rewrite

Genesis is the private development/value factory of Gnozis.

## Responsibilities
- develop capabilities and modules;
- validate opportunities;
- build solutions and products;
- protect private implementation and commercial IP;
- expose only authorized interfaces/results to Gnozis Platform.

## Boundaries
Genesis may consume Core authority and authorized Platform contracts. Public users must not receive Genesis internals by default.

## Rewrite rule
Existing code and context are evidence only. Extract contracts and invariants, then rewrite into the target boundary.
